Analysis Capabilities

Composite Index

Multi-indicator welfare index with z-score normalization, freshness-weighted scoring, and country ranking.

Anomaly Detection

Isolation Forest algorithm identifies unusual patterns in health, food price, and education indicators.

Trend Analysis

Moving averages and polynomial regression detect increasing, decreasing, or stable trends.

Food Security

IPC phase classification, caloric deficit calculation, food price volatility monitoring with alert thresholds.

Inequality Metrics

Gini coefficient, Palma ratio, decile analysis, and inequality trend detection via linear regression.

Healthcare Index

Normalized composite health access index with country ranking and statistical outlier detection.

UN Data Exchange Standards

SDMX-CSV Export

SDMX 2.0 compliant CSV output with DATAFLOW, REF_AREA, INDICATOR, TIME_PERIOD, OBS_VALUE columns. Standard format for UN statistical data exchange (ISO 17369).

HXL-Tagged CSV

Humanitarian Exchange Language hashtag rows for HDX platform compliance. Tags include #country+name, #date+year, #indicator+value+num, #severity+text.

UN Engagement Roadmap

  1. 1

    HDX Platform In Progress

    Automated weekly dataset publishing to Humanitarian Data Exchange via hdx-python-api. 4 datasets configured: economic indicators, health indicators, disaster alerts, food price indices.

  2. 2

    UN Global Pulse Partnership

    Project collaboration proposal drafted. Open-source welfare monitoring using multi-source public data integration. Apply via unglobalpulse.org.

  3. 3

    ECOSOC Consultative Status

    Long-term goal. Application checklist prepared. Next deadline: June 1, 2026. Requires 2+ years of formal operation, charter, and financial statements.

  4. 4

    World Bank Microdata Library

    DDI-compatible metadata for cross-country welfare datasets. Submission requires data from low and middle-income countries with clear usage terms.
